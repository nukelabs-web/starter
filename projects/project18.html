PROJECT 18: DIGITAL TUG OF WAR

1D Competitive Gaming

Difficulty: Medium
Concepts: Game Logic
Time: 45 Min

Mission Brief

It's time to settle scores. In this project, you will build a digital version of Tug of War. The center light acts as the "flag" on the rope. Two players must mash their buttons as fast as possible to pull the light to their side. First to reach the edge wins!

Key Components

  • Arduino Uno R3
  • 2x Push Buttons
  • 5x LEDs
  • 7x Resistors (5 for LEDs, 2 for Buttons)
  • Jumper Wires

Step-by-Step Instructions

  1. Place two buttons on opposite ends of the breadboard.
  2. Connect the Left Button to Pin 2 and the Right Button to Pin 12 (Use 10k resistors for pull-down to GND).
  3. Place 5 LEDs in a row between the buttons.
  4. Connect the LEDs (Left to Right) to pins 3, 5, 6, 9, 10.
  5. Ensure all LED cathodes connect to GND via resistors.
  6. Connect 5V and GND rails.
  7. Upload the code below.

How It Works

  • Edge Detection:
  • Rising Edge:
    In a mashing game, we can't just check `if(button == HIGH)`. If we did, holding the button down would instantly move the light. We need to detect when the button changes from LOW to HIGH. We do this by comparing `currentState` vs `lastState`.
  • The Array:
    The 5 LEDs are mapped to `{3, 5, 6, 9, 10}`. The variable `position` acts as the index. If `position` is 2, we light up `leds[2]` (Pin 6).

Expected Output

When the game starts, all lights flash. Then the center light turns on. As Player 1 presses the Left button, the light jumps left. As Player 2 presses Right, it jumps right. When the light hits either edge, it flashes to signal victory.

What You Learned

  • How to create game logic using variables (`position`).
  • Implementing "State Change Detection" for button presses.
  • Using arrays to map logical order (0-4) to physical pins.
