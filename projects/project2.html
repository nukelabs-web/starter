PROJECT 02: LED SEQUENCER

Mastering Loops and Arrays

Difficulty: Easy
Concepts: Loops & Arrays
Time: 30-45 Min

Project Summary

This project takes digital output to the next level. Instead of blinking one LED, you will wire multiple LEDs and use programming "loops" to create a running light effect (like Knight Rider or airport runway lights).

Key Components

  • Arduino Uno R3
  • 5x LEDs (Red or Mixed)
  • 5x 220Ω Resistors
  • 10+ Jumper Wires
  • Breadboard

Circuit Diagram

Pin Connections

Arduino Pin Component Connection
Pins 2, 3, 4, 5, 6 Positive Legs (Anodes) of 5 LEDs
GND All Negative Legs (via separate resistors or common rail)

Step-by-Step Instructions

  1. Place 5 LEDs on the breadboard in a row, spacing them out slightly.
  2. Connect a 220Ω resistor to the cathode (short leg) of EACH LED, going to the negative rail.
  3. Connect the negative rail of the breadboard to the Arduino GND pin.
  4. Connect jumper wires from the Anode (long leg) of each LED to pins 2, 3, 4, 5, and 6 respectively.
  5. Open Arduino IDE, paste the code below, and upload.

Arduino Code

/* Project 2 - LED Sequencer * Hardware: 5 LEDs connected to pins 2 through 6. * Purpose: Demonstrate For Loops and Arrays. */ void setup() { // Use a for loop to initialize pins 2 through 6 as outputs for (int pin = 2; pin <= 6; pin++) { pinMode(pin, OUTPUT); } } void loop() { // Turn LEDs on one by one for (int pin = 2; pin <= 6; pin++) { digitalWrite(pin, HIGH); // Turn LED on delay(100); // Wait fast digitalWrite(pin, LOW); // Turn LED off } // Optional: Reverse direction loop could be added here }

How It Works

  • Code Logic:
  • For Loops:
    Instead of writing digitalWrite 5 separate times, we use a loop: for (int pin = 2; pin <= 6; pin++).
  • Automation:
    The variable pin increases by 1 every time the loop runs, allowing us to control the next LED in the line automatically.
  • Delay Speed:
    Changing delay(100) to a smaller number makes the light "run" faster.
  • Hardware Note:
  • Current Limiting:
    Each LED must have its own resistor. Sharing one resistor for all 5 LEDs will result in uneven brightness or failure.

Expected Output

The LEDs should light up one after another from left to right rapidly, creating a "wave" or "chase" effect that repeats indefinitely.

What You Learned

  • How to wire multiple components sharing a common Ground connection.
  • How to use for loops to automate repetitive tasks in code.
  • How to manipulate variables to control hardware pins dynamically.

Next Steps / Extension Ideas

Try making the lights bounce back and forth (Knight Rider style), or attach a potentiometer to control the speed of the sequence.
