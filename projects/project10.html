PROJECT 10: LIGHT METER

Visualizing Sensor Data

Difficulty: Medium
Concepts: Data Viz
Time: 30-45 Min

Mission Brief

Instead of a simple ON/OFF switch, we will build a smart meter that visualizes how much light there is. We will use three LEDs (Red, Yellow, Green) to represent Low, Medium, and High light levels.

Key Components

  • Arduino Uno R3
  • LDR Sensor + 10kΩ Resistor
  • 3x LEDs (Red, Yellow, Green)
  • 3x 220Ω Resistors
  • Jumper Wires

Circuit Diagram

Pin Connections

Arduino Pin Component Connection
Pin A0 LDR Sensor Signal
Pin 2 Red LED (Low Light)
Pin 3 Yellow LED (Medium Light)
Pin 4 Green LED (High Light)

Step-by-Step Instructions

  1. Build the LDR Voltage Divider circuit (from Project 4) connected to A0.
  2. Connect the Red LED to Pin 2, Yellow to Pin 3, and Green to Pin 4.
  3. Crucial: Ensure every LED has its own 220Ω series resistor connected to GND.
  4. Upload the code below.
  5. Use the Serial Monitor to check your room's light values if the LEDs don't light up as expected.

Arduino Code

/* Project 10 - Light Level Meter * Visualizes light intensity using 3 LEDs. */ const int sensorPin = A0; const int redLed = 2; const int yellowLed = 3; const int greenLed = 4; void setup() { pinMode(redLed, OUTPUT); pinMode(yellowLed, OUTPUT); pinMode(greenLed, OUTPUT); Serial.begin(9600); } void loop() { int val = analogRead(sensorPin); Serial.print("Value: "); Serial.println(val); // Reset all LEDs to OFF first digitalWrite(redLed, LOW); digitalWrite(yellowLed, LOW); digitalWrite(greenLed, LOW); // Logic: Bucketing the values if (val < 300) { digitalWrite(redLed, HIGH); // Dark (Low) } else if (val >= 300 && val < 700) { digitalWrite(yellowLed, HIGH); // Dim (Medium) } else { digitalWrite(greenLed, HIGH); // Bright (High) } delay(100); }

How It Works

  • Programming Logic (Bucketing):
  • Range Splitting:
    The sensor gives us 0-1023. We split this huge range into three small "buckets":
    1. 0 to 300 (Dark)
    2. 300 to 700 (Medium)
    3. 700+ (Bright)
  • Else If:
    This structure is crucial. We check the first condition. If false, we check the second. If that is also false, the `else` (default) runs.
  • Hardware Concept:
  • Visual Feedback:
    Humans aren't good at reading raw numbers like "642". We are very good at seeing colors. This project translates raw data into a human-readable format.

Expected Output

Dark Room: Red LED turns ON.
Normal Light: Yellow LED turns ON.
Flashlight: Green LED turns ON.
Only one LED should be lit at a time, acting like a gauge.

What You Learned

  • Using `else if` to create multiple logical conditions.
  • Visualizing analog data using digital outputs.
  • How to define numerical ranges in code (`val >= 300 && val < 700`).

Next Steps / Extension Ideas

Add 5 LEDs to create a more precise bar graph (like a battery indicator). Or use the `map()` function to convert the sensor data directly into an LED count.
