PROJECT 07: CODE LOCK

Logic & Security Systems

Difficulty: Medium
Concepts: Logic Gates
Time: 30-40 Min

Mission Brief

Build a digital security system! The Red LED (Locked) will stay on by default. The Green LED (Unlocked) will only turn on if you trigger the correct "key" combination using two buttons simultaneously.

Key Components

  • Arduino Uno R3
  • 2x Push Buttons
  • 1x Red LED
  • 1x Green LED
  • 2x 10kΩ Resistors (Pull-down)
  • 2x 220Ω Resistors (LEDs)

Circuit Diagram

Pin Connections

Arduino Pin Component Connection
Pin 2 Button A (Input)
Pin 3 Button B (Input)
Pin 12 Red LED (Locked Status)
Pin 13 Green LED (Unlocked Status)

Step-by-Step Instructions

  1. Place both buttons on the breadboard with space between them.
  2. Connect 10kΩ pull-down resistors to one leg of EACH button (connected to GND).
  3. Connect the other leg of EACH button to 5V.
  4. Connect the signal leg (same side as resistor) of Button A to Pin 2, and Button B to Pin 3.
  5. Wire the Red LED to Pin 12 and Green LED to Pin 13 (don't forget 220Ω resistors!).
  6. Upload the code logic below.

Arduino Code

/* Project 7 - Code Lock * Requires Button A (Pin 2) and Button B (Pin 3) * to be pressed TOGETHER to unlock. */ int btnA = 2; int btnB = 3; int redLed = 12; // Locked Indicator int greenLed = 13; // Unlocked Indicator void setup() { pinMode(btnA, INPUT); pinMode(btnB, INPUT); pinMode(redLed, OUTPUT); pinMode(greenLed, OUTPUT); } void loop() { // Logic: IF Button A is pressed AND (&&) Button B is pressed if (digitalRead(btnA) == HIGH && digitalRead(btnB) == HIGH) { // Access Granted digitalWrite(greenLed, HIGH); digitalWrite(redLed, LOW); } else { // Access Denied (Locked) digitalWrite(greenLed, LOW); digitalWrite(redLed, HIGH); } }

How It Works

  • Programming Logic (AND Gate):
  • The && Operator:
    In coding, && means "AND". The statement if (A && B) only runs if BOTH conditions are true at the exact same time.
  • Default State (Else):
    If you press just one button (or no buttons), the else block runs, keeping the Red LED on (Locked).
  • Security Concept:
  • Dual Authentication:
    This mimics real-world systems like nuclear launch keys or safe deposit boxes where two keys must be turned simultaneously.

Expected Output

Standard State: Red LED is ON.
Press Button A only: Red stays ON.
Press Button B only: Red stays ON.
Press BOTH Buttons: Red turns OFF, Green turns ON.

What You Learned

  • How to use Logical Operators (AND `&&`, OR `||`).
  • Building basic security logic with hardware.
  • Handling multiple inputs simultaneously in a single if statement.

Next Steps / Extension Ideas
