PROJECT 05: DUAL LED FADING

Multi-Channel Analog Output

Difficulty: Medium
Concepts: PWM Control
Time: 25 Min

Mission Brief

Digital pins are usually just On or Off. In this project, we utilize Pulse Width Modulation (PWM) on two separate pins to create a smooth fading animation between two different LEDs.

Key Components

  • Arduino Uno R3
  • 2x LEDs
  • 2x Resistors
  • Jumper Wires
  • Breadboard

Circuit Diagram

Pin Connections

Arduino Pin Component Connection
Pin 3 Wire to First LED Anode (+)
Pin 5 Wire to Second LED Anode (+)
GND Wire to Negative Rail (Common Ground)

Step-by-Step Instructions

  1. Connect the Arduino GND pin to the blue Negative Rail on the breadboard.
  2. Insert two LEDs into the breadboard.
  3. Connect a resistor from the Cathode (Short Leg) of each LED to the Negative Rail.
  4. Connect the Anode (Long Leg) of the first LED to Pin 3.
  5. Connect the Anode (Long Leg) of the second LED to Pin 5.
  6. Upload the code below.

Arduino Code

/* Project 5 - Dual Fading * Fades two LEDs on PWM pins 3 and 5. */ int led1 = 3; // First LED on PWM pin int led2 = 5; // Second LED on PWM pin void setup() { pinMode(led1, OUTPUT); pinMode(led2, OUTPUT); } void loop() { // Fade LED 1 IN for (int i = 0; i <= 255; i += 5) { analogWrite(led1, i); delay(15); } // Fade LED 1 OUT for (int i = 255; i >= 0; i -= 5) { analogWrite(led1, i); delay(15); } // Fade LED 2 IN for (int i = 0; i <= 255; i += 5) { analogWrite(led2, i); delay(15); } // Fade LED 2 OUT for (int i = 255; i >= 0; i -= 5) { analogWrite(led2, i); delay(15); } }

How It Works

  • Hardware Theory (PWM):
  • PWM Pins:
    Not all pins can fade. We must use pins marked with `~`. We selected pins 3 and 5 because they both support PWM output.
  • analogWrite(pin, value):
    This function sends a rapid pulse signal. 0 is always off, 255 is always on, and 127 is 50% duty cycle (half brightness).
  • Code Logic:
  • Sequential Loops:
    The code runs 4 distinct loops in order. First it fades LED 1 Up, then Down. Once that finishes, it moves to LED 2 Up, then Down.

Expected Output

The first LED will gently fade on and off. Immediately after it finishes, the second LED will fade on and off. This cycle repeats indefinitely.

What You Learned

  • How to wire multiple output devices with a common ground.
  • Using multiple PWM pins simultaneously.
  • Sequencing animations using code loops.

Next Steps / Extension Ideas

Try modifying the code so BOTH LEDs fade in at the same time, or make one fade IN while the other fades OUT (Cross-fading).
