PROJECT 05: LED FADING

Analog Output via PWM

Difficulty: Medium
Concepts: PWM
Time: 20 Min

Mission Brief

Digital pins are usually 0V or 5V. But what if you want 2.5V to make an LED half-bright? We use Pulse Width Modulation (PWM) to simulate analog voltages.

Key Components

  • Arduino Uno
  • LED
  • 220Ω Resistor
  • Breadboard

Pin Connections

Arduino PinComponent
Pin 9 (PWM ~)Positive Leg (Anode) of LED
GNDNegative Leg via Resistor

Circuit Diagram

Arduino Code

int ledPin = 9; // LED connected to digital pin 9 void setup() { // nothing happens in setup } void loop() { // fade in from min to max in increments of 5 points: for (int fadeValue = 0 ; fadeValue <= 255; fadeValue += 5) { analogWrite(ledPin, fadeValue); delay(30); } // fade out from max to min in increments of 5 points: for (int fadeValue = 255 ; fadeValue >= 0; fadeValue -= 5) { analogWrite(ledPin, fadeValue); delay(30); } }

How It Works

  • PWM Pins (~):
    On the Arduino, pins marked with `~` (3, 5, 6, 9, 10, 11) support fading.
  • analogWrite(pin, value):
    Takes a value between 0 (OFF) and 255 (Full Brightness).
  • The Logic:
    We use two loops. One counts UP to 255 (Fade In), the other counts DOWN to 0 (Fade Out).
