PROJECT 14: MULTI-SENSOR HUB

Advanced Integrated System

Difficulty: Hard
Concepts: System Integration
Time: 60 Min

Mission Brief

Real-world robots use multiple sensors simultaneously. In this capstone project, you will build a smart dashboard that monitors both distance (Sonar) and environmental light (LDR), displaying the status on LEDs and alerting via a buzzer.

Key Components

  • Arduino Uno R3
  • HC-SR04 Ultrasonic Sensor
  • LDR Light Sensor
  • Piezo Buzzer
  • 3x LEDs (Red, Yellow, Green)
  • Resistors
  • Jumper Wires

Circuit Diagram

Step-by-Step Instructions

  1. Power Bus: Connect 5V and GND to the breadboard rails.
  2. Sonar: Connect Trig to Pin 12, Echo to Pin 11, VCC/GND to rails.
  3. Light: Build the LDR Voltage Divider and connect the signal to Pin A0.
  4. Outputs: Connect LEDs to Pins 2, 3, 4 (with resistors). Connect Buzzer to Pin 8.
  5. Verify: Double-check all ground connections are shared.
  6. Upload the code below.

Arduino Code

/* Project 14 - Multi-Sensor Hub * 1. Checks Distance: Lights up LEDs based on proximity. * 2. Checks Light: If too dark, turns on "Night Mode" (All LEDs Blink). * 3. Buzzer: Beeps if object is very close. */ const int trigPin = 12; const int echoPin = 11; const int buzzer = 8; const int greenLed = 2; const int yellowLed = 3; const int redLed = 4; const int ldrPin = A0; void setup() { pinMode(trigPin, OUTPUT); pinMode(echoPin, INPUT); pinMode(buzzer, OUTPUT); pinMode(greenLed, OUTPUT); pinMode(yellowLed, OUTPUT); pinMode(redLed, OUTPUT); Serial.begin(9600); } void loop() { // --- PART 1: READ SENSORS --- int lightLevel = analogRead(ldrPin); digitalWrite(trigPin, LOW); delayMicroseconds(2); digitalWrite(trigPin, HIGH); delayMicroseconds(10); digitalWrite(trigPin, LOW); long duration = pulseIn(echoPin, HIGH); int distance = duration * 0.034 / 2; Serial.print("Dist: "); Serial.print(distance); Serial.print("cm | Light: "); Serial.println(lightLevel); // --- PART 2: LOGIC --- // If it's pitch black, Panic Mode! if (lightLevel < 200) { digitalWrite(greenLed, HIGH); digitalWrite(yellowLed, HIGH); digitalWrite(redLed, HIGH); delay(100); digitalWrite(greenLed, LOW); digitalWrite(yellowLed, LOW); digitalWrite(redLed, LOW); delay(100); return; // Skip the rest of the loop } // Normal Distance Logic digitalWrite(greenLed, LOW); digitalWrite(yellowLed, LOW); digitalWrite(redLed, LOW); noTone(buzzer); if (distance < 10) { digitalWrite(redLed, HIGH); tone(buzzer, 1000); } else if (distance < 20) { digitalWrite(yellowLed, HIGH); } else { digitalWrite(greenLed, HIGH); } delay(100); }

How It Works

  • Priority Logic:
  • Interrupting Behavior:
    The code checks light levels first. If it is "pitch black" (`lightLevel < 200`), it enters a flashing panic mode and uses `return` to skip the distance check entirely. This mimics a system override.
  • Normal Operation:
    If the light is normal, the system proceeds to measure distance and act as a standard parking sensor (Green/Yellow/Red logic).

Expected Output

Daytime: The LEDs change based on how close your hand is (Green -> Yellow -> Red + Beep).
Darkness: If you cover the LDR completely, all three LEDs will flash rapidly in a panic pattern.

What You Learned

  • How to read multiple sensors in a single loop cycle.
  • Using `return` to exit a loop early based on priority conditions.
  • Managing complex wiring with shared power rails.
