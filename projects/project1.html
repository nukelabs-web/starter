PROJECT 01: BLINKING LED

Arduino Uno R3 project

Difficulty: Easy
Concepts: Digital Output
Time: 15-45 Min

Project Summary

This project demonstrates Digital output and basic programming. Build it to learn practical aspects of digital output and timing logic.

Key Components

  • Arduino Uno R3
  • LED
  • 220Ω Resistor
  • Jumper Wires
  • Breadboard

Circuit Diagram

Pin Connections

Arduino Pin Component Connection
Pin 13 Positive Leg (Anode) of LED
GND Negative Leg (Cathode) of LED

Step-by-Step Instructions

  1. Gather the components and assemble on a breadboard as shown in the circuit diagram.
  2. Double-check wiring and resistor connections; ensure correct polarity for LEDs.
  3. Open Arduino IDE, paste the sketch, select board/port, and upload.
  4. Use Serial Monitor for calibration if the sketch prints values.

Arduino Code

/* Project 1 - Blinking LED * Hardware: LED with 220Ω resistor connected from pin 13 to GND. * Purpose: Introduce digital output and timing using delay(). */ int ledPin = 13; // use on-board LED on many Arduino boards void setup() { pinMode(ledPin, OUTPUT); // configure pin as output to drive the LED } void loop() { digitalWrite(ledPin, HIGH); // set pin HIGH -> LED ON delay(500); // wait 500 ms digitalWrite(ledPin, LOW); // set pin LOW -> LED OFF delay(500); // wait 500 ms }

How It Works

  • Line-by-line justification:
  • int ledPin = 13; — stores the pin number so it's easy to change.
  • pinMode(ledPin, OUTPUT); — sets the pin as an output so digitalWrite can drive it.
  • digitalWrite(ledPin, HIGH); — applies voltage to the pin to turn LED on.
  • delay(500); — a blocking wait; simple but stops microcontroller from doing other tasks.
  • Digital / Analog I/O Notes:
  • Digital pins set with pinMode() drive outputs (HIGH/LOW). AnalogRead reads sensors (0-1023). PWM via analogWrite uses timers to simulate analog voltages.

Expected Output

The project will perform the described behavior (LEDs/buzzer/display) when wired and uploaded correctly. Use Serial Monitor for debugging and calibration.

What You Learned

  • How to program Arduino digital and analog pins
  • How to debug using Serial Monitor
