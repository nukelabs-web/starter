PROJECT 01: BLINKING LED

Introduction to Digital Output & Timing

Difficulty: Easy
Time: 15-45 Min

Mission Brief

This project demonstrates Digital Output and Basic Programming. You will build a simple circuit to control an LED, learning the fundamental concepts of controlling hardware with software.

Key Components

  • Arduino Uno R3
  • LED (Any Color)
  • 220Ω Resistor
  • Jumper Wires
  • Breadboard

Pin Connections

Arduino Pin Component
Pin 13 Positive Leg (Anode) of LED
GND Negative Leg (Cathode) of LED

Circuit Diagram

Source Code

/* Project 1 - Blinking LED * Hardware: LED with 220Ω resistor connected from pin 13 to GND. */ int ledPin = 13; // LED connected to digital pin 13 void setup() { pinMode(ledPin, OUTPUT); // sets the digital pin as output } void loop() { digitalWrite(ledPin, HIGH); // sets the LED on delay(500); // waits for a second digitalWrite(ledPin, LOW); // sets the LED off delay(500); // waits for a second }
